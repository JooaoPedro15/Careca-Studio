# Legacy Modules

Este arquivo registra modulos que existiram no Careca Studio, mas nao fazem mais parte do escopo ativo do app.

## Partner Scout

- Status: extraido para um repositorio separado chamado `partner-scout`.
- Motivo: o Careca Studio agora foca em ferramentas de edicao; prospeccao comercial pertence ao eixo de inteligencia de criadores.
- Destino previsto: futuramente pode ser integrado ao Creator Intelligence Platform.
- Codigo ativo no Careca Studio: removido.

## Media Kit

- Status: removido do shell ativo do Careca Studio.
- Motivo: modulo comercial fora do novo foco do app.
- Codigo ativo no Careca Studio: removido.

## Game Recommendation / Game Scout

- Status: nao faz parte do escopo atual.
- Motivo: recomendacao e pesquisa de oportunidades nao sao ferramentas de edicao.
- Codigo ativo no Careca Studio: nao mantido como modulo ativo.
